# Puntos Santana

App de fidelización de Santana del Río Mall Comercial (puntos, sellos, premios, cupones y mensajes).

- `#/` — app de clientes (cédula + PIN)
- `#/personal` — administrador y puntos recaudadores (Pilatos, Derek)

Base de datos: Supabase (proyecto "Puntos Santana"). Sitio estático en `public/`.
